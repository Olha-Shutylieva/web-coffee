Редагування: Капучино

Форма заповнена поточними даними позиції. Скидання повертає ці початкові значення, а не порожні поля.

Основні дані

Формат: дві великі латинські літери, дефіс і три цифри, наприклад CF-014.

Ціле число без одиниць: мілілітри для напоїв або грами для десертів.

Дата від 2024-01-01 до 2027-12-31.

Опис і наявність

Поточне зображення: images/cappuccino.svg. Новий файл можна обрати нижче.

Файл SVG, WebP або PNG. Поле файлу не зберігає попереднє значення.
