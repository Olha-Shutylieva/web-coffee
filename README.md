# Кав'ярня «Зерно & Смак» (Web Coffee)

Навчальний вебпроєкт сайту кав'ярні: каталог авторських напоїв і десертів, сторінки деталей, інформація про кав'ярню та панель адміністрування.

## 📌 Основні можливості та сторінки

- **Каталог (`index.html`)**: перегляд асортименту страв та напоїв (кава, чай, десерти, сезонне меню), фільтрація за категоріями, сортування та бейджі наявності.
- **Сторінка позиції (`details.html`)**: детальний опис позиції меню, хлібні крихти, таблиця характеристик та харчової цінності, список інгредієнтів.
- **Про кав'ярню (`about.html`)**: історія закладу, концепція, контакти, години роботи, відеопрезентація та блок частих запитань (FAQ).
- **Адміністрування (`admin.html`)**: таблиця списку всіх позицій меню з інформацією про ціну, об'єм/вагу, категорію, статус наявності та діями редагування/видалення.
- **Створення / Редагування позиції (`admin-edit.html`)**: форма додавання та редагування позиції меню з повною валідацією полів.

## 🎨 Стилізація та архітектура CSS

Стилі проєкту організовані в єдиному файлі `css/main.css` із дотриманням сучасних стандартів CSS:

### 1. Каскадні шари (`@layer`)
Таблиця стилів структурована за пріоритетністю за допомогою директиви `@layer`:
- `@layer reset`: нормалізація та скидання базових стилів (`box-sizing: border-box`, `max-inline-size: 100%` для медіа, скидання margin/padding).
- `@layer base`: токени дизайну, базова типографіка, посилання, списки, таблиці, заголовки.
- `@layer components`: BEM-компоненти інтерфейсу (шапка, картки, навігація, форми, бейджі, таблиці, акордеони FAQ).
- `@layer utilities`: допоміжні утилітарні класи.

### 2. Дизайн-токени (CSS Custom Properties)
Усі ключові параметри винесені у змінні на рівні `:root`:
- **Кольорова палітра**:
  - `--color-bg` — основне тепле тло сторінки (`#faf7f2`).
  - `--color-surface` — тло карток та блоків (`#ffffff`).
  - `--color-text` — основний колір тексту глибокого кавового відтінку (`#261911`).
  - `--color-text-muted` — приглушений другорядний текст (`#7a6a5d`).
  - `--color-accent` / `--color-accent-hover` — фірмовий теплий теракотовий акцент (`#c24117`).
  - `--color-border` — колір рамок та роздільників (`#e2d6c8`).
  - `--color-focus` — помітне кільце фокусу (`#c24117`).
  - `--color-error` — колір помилки валідації (`#b91c1c`).
  - `--color-success` / `--color-danger` — статусні кольори наявності.
- **Типографіка**:
  - `--font-main` — системний шрифт для основного тексту (`system-ui`, `-apple-system`, `Segoe UI`, `Roboto`, `sans-serif`).
  - `--font-heading` — виразний геометричний шрифт для заголовків.
- **Шкала відступів**: `--space-xs` (0.25rem), `--space-s` (0.5rem), `--space-m` (1rem), `--space-l` (1.5rem), `--space-xl` (2rem).
- **Радіуси заокруглення**: `--radius-s`, `--radius-m`, `--radius-l`, `--radius-pill`.
- **Тіні**: багатошарові м'які тіні `--shadow-sm`, `--shadow-md`, `--shadow-lg`.

### 3. Темна тема (Dark Mode)
- Підтримка темної теми реалізована через `color-scheme: light dark` та медіазапит `@media (prefers-color-scheme: dark)`.
- Автоматично адаптується під системні налаштування операційної системи шляхом перевизначення токенів кольорів.
- Відповідає вимогам контрастності WCAG (контраст тексту > 4.5:1, елементів керування > 3:1).

## ♿ Доступність (Accessibility)

- **Клавіатурна навігація**: стилізований видимий фокус `:focus-visible` для інтерактивних елементів (кнопки, посилання, інпути).
- **ARIA-атрибути**: використання `aria-current="page"` для навігації, `aria-describedby` для підказок у формах.
- **Семантична валідація**: стани валідації `:user-invalid` поєднують зміну кольору рамки з додатковою текстовою/графічною ознакою помилки.
- **Хлібні крихти**: роздільники між пунктами додаються псевдоелементом `::before`, зберігаючи семантичну чистоту розмітки.

## 📁 Структура проєкту

```text
web-coffee/
├── css/
│   └── main.css            # Головна таблиця стилів (шари reset, base, components, utilities)
├── docs/
│   ├── css-validator.txt   # Підтвердження валідності CSS у W3C Validator
│   └── model.md            # Словник полів та специфікація моделі даних
├── images/                 # Векторні (SVG) та растрові (WebP) зображення меню й логотип
├── js/
│   └── app.js              # Скрипти клієнтської логіки (за потреби)
├── media/                  # Відео та субтитри (VTT) для промо-матеріалів
├── about.html              # Сторінка «Про кав'ярню» та FAQ
├── admin.html              # Панель керування асортиментом
├── admin-edit.html         # Форма додавання / редагування позиції
├── details.html            # Детальна сторінка позиції меню
├── index.html              # Головна сторінка каталогу
└── README.md               # Документація проєкту
```

## 🚀 Як відкрити проєкт

1. Склонуйте або завантажте репозиторій.
2. Відкрийте будь-який HTML-файл (наприклад, `index.html`) безпосередньо у браузері або скористайтеся локальним статичним сервером (наприклад, розширенням Live Server у VS Code або вбудованим сервером WebStorm / IntelliJ IDEA).
