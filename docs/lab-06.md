# Лабораторна робота №6. Flexbox

Предметна область — меню кав'ярні. Токени, каскадні шари й оформлення з лабораторної №5 не змінювались. Правила компонування додані в шар `components` файлу `css/main.css`. Власний JavaScript не використовується. Властивості `order`, `row-reverse` і `column-reverse` для змістових елементів немає: порядок фокусу збігається з порядком у розмітці.

## Що скомпоновано

- Шапка — гнучкий рядок з `flex-wrap` і `align-items: center`. Назва й навігація стоять на початку, поле пошуку відсунуте `margin-inline-start: auto`. Пункти меню — окремий ряд із `gap`. Форма пошуку — рядок «поле — дія».
- Хлібні крихти — ряд із перенесенням. Роздільник `›` є частиною пункту (`::before` усередині гнучкого елемента), тож не переноситься окремо.
- Підвал — `display: flex` з `justify-content: space-between` і перенесенням блоків.
- Панель фільтрів каталогу — одна форма: пошук, сортування і група категорій. Категорії — перемикачі `name="category"` (`coffee`, `tea`, `dessert`, `seasonal` і порожнє значення «Усі») у `fieldset` з `legend`, оформлені як чипи. Поле приховане через `opacity: 0`, не через `display: none`. Обраний чип має акцентне тло, наведення змінює рамку, фокус клавіатури дає кільце на чипі.
- Картка — стовпчик. Нижній блок (бейдж, позначка наявності, ціна й об'єм) має `margin-block-start: auto`. Довга назва не розпирає картку: `min-inline-size: 0` і перенесення тексту.
- Перелік карток — `flex-wrap: wrap`, кожна позиція `flex: 1 1 18rem`, відступи через `gap`.
- Сторінка деталей: фото і характеристики в рядку з перенесенням; кожна пара `dt`/`dd` — власний гнучкий рядок з однаковою базою назви `9rem`; зміст «На цій сторінці» — ряд із перенесенням.
- Форми: оцінки відгуку в рядку, кнопки в `.form__actions` з перенесенням, прапорець вирівняний по центру поперечної осі. Дії таблиці адміністрування — гнучкий рядок у клітинці. Сама таблиця лишається таблицею; на вузькому екрані вона прокручується всередині `.table-scroll`, а не розтягує сторінку.

## Спостереження у Flexbox

На ширині 1280 CSS-пікселів картки стають у три ряди: 3 + 3 + 2.

У другому ряді картка «Матча Лате» має короткий опис, «Чізкейк Нью-Йорк» — довгий. Висота всіх трьох карток ряду однакова (534px), бо елементи розтягуються вздовж поперечної осі. У DevTools вільний простір коротшої картки забирає не опис, а зовнішній відступ `.card__footer`: обчислене `margin-block-start` для матча — 90px, для чізкейка — 0px. Через це ціни в ряду мають одну вертикальну координату (1372px).

Останній ряд містить дві картки шириною 544px замість 352px у повних рядах. `flex-grow: 1` віддає їм увесь вільний простір рядка, тож неповний ряд виглядає інакше за повні. Це відоме обмеження перенесення Flexbox; у лабораторній №7 його замінить сітка Grid.

На ширині 320 CSS-пікселів `documentElement.scrollWidth` дорівнює ширині вікна на всіх п'яти сторінках: горизонтальної прокрутки документа немає. Таблиця порцій і таблиця адміністрування ширші за вікно, але прокручуються у власному контейнері.

## Перевірка

- Клік по чипу «Кава» вмикає відповідний перемикач і фарбує чип у `--color-accent`. Група лишається звичайними radio з одним `name`, тож стрілки клавіатури змінюють вибір без скриптів.
- Обхід каталогу клавішею Tab іде за розміткою: шапка, пошук, фільтри й чипи, далі назви карток і кнопки зліва направо, зверху вниз.
- CSS W3C Validator, профіль CSS level 3, 2026-11-18: помилок немає.
- W3C Nu Html Checker, 2026-11-18: `index.html`, `about.html`, `details.html`, `admin.html`, `admin-edit.html` валідні.
